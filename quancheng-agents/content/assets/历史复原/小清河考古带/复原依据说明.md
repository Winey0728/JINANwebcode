## 一、史实概要（写作与画面叙事依据）

- **名称**：小清河考古带（暂用名）【存疑】——沿小清河两岸分布的多处古代遗址群的统称，非单一遗址的正式命名。
- **地理位置**：沿小清河（济南市境内段）两岸分布，西起槐荫区，历城、章丘，东至邹平、博兴等地；济南市区段主要流经天桥区、历城区。
- **小清河概况**：
  - 小清河发源于济南市泉群（趵突泉、黑虎泉等泉水汇流而成），东流至莱州湾入海，全长约 237 公里；
  - 开凿于南宋绍兴年间（约 1130—1160 年）【存疑】——有学者认为小清河是在古济水故道基础上疏浚而成，开凿年代有不同说法；
  - 历史上是山东北部重要的水运通道，承担盐运、粮运、商贸运输功能；
  - 宋元时期小清河航运兴盛，沿岸形成多处码头与聚落。
- **考古发现**：
  - 沿小清河两岸分布有多处史前聚落遗址（大汶口文化、龙山文化）、商周遗址、汉唐墓葬、宋元码头遗址等【存疑】——具体遗址数量、位置、年代、出土器物需考古调查报告确认；
  - 济南市考古研究院曾开展小清河沿线考古调查，发现多处遗址点；
  - 部分遗址因河道整治、城市建设被破坏或淹没，考古资料不完整。
- **复原策略**：
  - 本场景选择复原**宋元时期小清河码头商贸场景**（小清河航运兴盛期），以"千年水道的繁华"为叙事基调；
  - 考古资料有限，以宋元时期山东地区水运与商贸的考古发现、文献记载为主要依据，结合小清河的历史功能进行**适度想象复原**，所有存疑处均已标注。

## 二、宋元时期小清河码头场景形制（画面复原核心依据）

### 2.1 河道与码头【存疑】——以小清河考古调查与同时期码头遗址为参照

| 部位 | 形制要点 |
|---|---|
| 河道 | 小清河面宽约 30—50 米（济南市区段），水流平缓，河水清澈（源自泉水）；河岸为土岸或石砌驳岸 |
| 码头 | 土筑或木石结构码头，伸入河面；码头面铺木板或石板；设有系船桩（木桩或石桩） |
| 泊船区 | 河面停泊货船、客船；船只多为平底木船，单桅或双桅，帆为竹篾编织或布帆 |
| 渡口 | 河边设简易渡口，有跳板连接河岸与船只 |
| 堤岸 | 河岸有土堤或石堤，堤上植柳树、芦苇；堤下为滩地 |

### 2.2 沿岸建筑与聚落

| 部位 | 形制要点 |
|---|---|
| 商铺 | 沿河岸建有商铺、客栈、茶馆，为单层或两层木结构建筑；坡屋顶，灰瓦或茅草；悬挑于河面或有柱廊 |
| 货栈 | 码头旁有仓储货栈，为宽大木构建筑，用于暂存货物；门前有装卸平台 |
| 民居 | 码头工人、船夫聚居区，为简朴的砖木或土木民居，院落紧凑 |
| 庙宇 | 河边可能有龙王庙或关帝庙，为传统中式庙宇建筑，飞檐翘角【存疑】——具体庙宇需考古与文献确认 |
| 街道 | 码头区街道为土路或石板路，宽约 3—5 米；两侧商铺招牌林立 |

### 2.3 商贸活动

| 类别 | 形制要点 |
|---|---|
| 货物 | 粮食（小麦、小米）、食盐、陶器、布匹、木材、煤炭、杂货等；货物以麻袋、竹筐、木桶盛装 |
| 交易 | 商铺前摆摊叫卖，货栈前装卸货物，船主与货主议价 |
| 运输 | 工人肩挑背扛搬运货物，独轮车、平板车在街道上穿行 |
| 船只 | 货船吃水较深，船舱敞开可见货物；客船有简易船篷；渔船较小，有渔网、鱼篓 |

### 2.4 时代特征（宋元时期）

- **人物服饰**：
  - 宋代：男子戴幞头、穿圆领袍或直裰；女子穿襦裙、披帛；商人穿短褐、系围裙；船夫赤裸上身或穿短褂、戴笠帽。
  - 元代：男子可能穿蒙古式袍服或汉服；女子穿襦裙或袍服；部分人物戴毡帽【存疑】——元代济南地区服饰的具体细节需图像史料确认。
- **交通工具**：船只（木船、帆船）、独轮车、平板车、马匹、轿子。
- **街景细节**：商铺招牌（竖排汉字）、幌子、布帘；货摊、量器（斗、秤）；水井、石墩、拴船桩。

### 2.5 环境与景观

- **植被**：河岸两侧植柳树、杨树、芦苇；远处为农田与村庄。
- **天气**：春夏之交或秋日，天气晴朗，河面微风；光线明亮，色调温暖。
- **声音想象**：船工号子、商贩叫卖、水波拍岸、车辙碾石——画面虽无声音，但构图应传达繁忙热闹的商贸氛围。
