## 一、史实概要（写作与画面叙事依据）

- **名称**：山东早期党史纪念馆，又名中共山东早期历史纪念馆。
- **位置**：济南市历下区五龙潭公园内（原中共山东省领导机关旧址所在地）。
- **主题**：记录山东党组织从诞生到发展壮大的光辉历程，重点展示王尽美、邓恩铭等济南籍早期共产党人的革命事迹。
- **山东党组织诞生**：
  - 1921 年春，王尽美、邓恩铭在济南发起建立济南共产主义小组，为山东地区最早的共产党组织；
  - 1921 年 7 月，王尽美、邓恩铭出席中国共产党第一次全国代表大会（上海—嘉兴），成为中共一大代表；
  - 1922 年，王尽美赴莫斯科出席远东各国共产党及民族革命团体第一次代表大会；
  - 1923 年，王尽美领导京汉铁路"二七"大罢工山东声援活动；
  - 1925 年 8 月，王尽美病逝于青岛，年仅 27 岁；1931 年 4 月，邓恩铭在济南英勇就义，年仅 30 岁。
- **纪念馆建筑**：现代仿古建筑，位于五龙潭公园内，紧邻中共山东省领导机关旧址（1923—1927 年山东省委机关所在地）。
- **复原策略**：纪念馆本身为现代建筑，故复原**1920 年代初期济南进步青年开展革命活动的室内场景**，以"火种初燃"为叙事基调。

## 二、1920 年代初期济南进步青年活动场景形制（画面复原核心依据）

### 2.1 活动场所

| 部位 | 形制要点 |
|---|---|
| 建筑类型 | 民国初期济南传统民居或学校教室/校舍，砖木结构，青砖墙、灰瓦坡屋顶 |
| 室内布局 | 简朴的民居正房或厢房，面积约 15—30 平方米；火炕或木床、方桌、条凳、木椅 |
| 照明 | 煤油灯或植物油灯（罩子灯），灯光昏黄，为室内主要光源；天花板上无电灯【存疑】——1920 年代济南部分区域已有电灯，但进步青年秘密集会场所多用油灯 |
| 门窗 | 木质格扇窗，糊白色窗纸或薄纱布；木门，可能有门帘 |
| 墙面 | 白灰墙面或青砖裸露，简朴无装饰；可能贴有报纸或手写标语 |
| 地面 | 青砖铺地或夯土地面 |

### 2.2 室内陈设

| 物品 | 形制要点 |
|---|---|
| 方桌 | 八仙桌或普通方木桌，桌上铺粗布或毛边纸 |
| 座椅 | 长条凳、圈椅或木椅，围桌而坐 |
| 灯具 | 煤油灯（玻璃罩、铜/铁底座），置于桌中央 |
| 书报 | 《新青年》《共产党宣言》（陈望道译本，1920 年出版）、《每周评论》等进步刊物；线装书或平装书 |
| 文房 | 毛笔、墨、砚台、粗纸；可能有一方小砚台和笔架 |
| 茶具 | 粗瓷茶壶、茶碗，置于桌角 |
| 衣物 | 长衫、中式棉袄挂于墙上木钩 |
| 其他 | 可能有柳条箱、包袱、雨伞等简单行李 |

### 2.3 人物形象

- **王尽美**（1898—1925）：济南人，面容清瘦，戴眼镜【存疑】——部分老照片显示其戴眼镜，度数不详，画面可弱化眼镜细节；身材中等；常穿长衫或粗布学生装；神情坚毅而温和。
- **邓恩铭**（1901—1931）：水族，贵州荔波人，身材较瘦削；穿长衫或学生装；神情机敏而坚定。
- **其他进步青年**：20 岁左右的青年学生或知识分子，穿长衫、学生装、粗布衣裳；围坐桌旁，或阅读、或书写、或低声讨论。
- **人物数量**：室内 3—6 人为宜，体现秘密集会的氛围。

### 2.4 时代氛围

- **时间**：1921—1922 年间，冬末春初或秋夜（室内场景不受季节限制，以油灯照明暗示夜晚）。
- **情感基调**：严肃而充满希望，青年们目光坚定，神情专注，体现"为理想而聚"的精神。
- **光线**：室内以煤油灯暖黄光为主，窗外可能有淡淡月光；光影对比强烈，营造私密、严肃的氛围。
