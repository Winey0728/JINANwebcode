## 一、史实概要（写作与画面叙事依据）

- **名称**：纬二路洋行旧址群，济南近代商埠"金融街"，素有"东方华尔街"之称。
- **位置**：济南市市中区纬二路，南北纵贯商埠区，北起经一路，南至经七路，与经二路十字交汇。纬二路为商埠区规划纵轴，与横轴经二路构成商埠骨架。
- **开埠背景**：1904 年济南自开商埠后，外国银行、华资银行、票号、钱庄等金融机构迅速聚集纬二路沿线，形成区域金融中心。商埠区的"金融街"功能定位与经二路的"商业街"形成功能互补。
- **核心机构**（纬二路沿线或附近，不同时期各有变迁）：
  - **德华银行**（Deutsch-Asiatische Bank）：德资银行，1904 年前后设立济南分行，是济南最早的外资银行之一。建筑为德式新古典主义风格，2—3 层，石材立面，庄重威严。
  - **交通银行**：华资银行，清末"户部银行"改组而来，济南分行设于商埠区，建筑为中西合璧风格。
  - **山东民生银行**：地方性华资银行，民国时期设立，服务山东地方实业。
  - **各类票号、钱庄**：山西票号（如日升昌、蔚泰厚等）及本地钱庄在商埠区设有分号，与银行并存，形成多层次金融体系。
- **建筑风貌**：纬二路洋行建筑以欧式古典主义为主流——德式、英式、法式风格并存，2—3 层砖石结构，立面严谨对称，柱廊、拱窗、山花、穹顶等元素丰富。部分华资银行采用中西合璧风格，西式立面配中式细部。建筑质量高、装饰精美，体现金融机构的雄厚资本与威严形象。
- **历史节点**：1904—1910 年代外资银行主导；1910—1920 年代华资银行崛起，中外金融机构并存；1930 年代达到鼎盛；1937 年后日军侵占，金融秩序遭破坏；1948 年济南战役后逐步恢复。

## 二、街区形制与建筑特征（画面复原核心依据）

### 2.1 街道格局

| 要素 | 形制要点 |
|---|---|
| 道路 | 纬二路宽约 15—20 米，碎石或石板路面，两侧设人行道；与经二路十字交汇处最为宽阔 |
| 街景 | 金融机构建筑沿街密排，建筑退界较经二路稍大，门前常设台阶与柱廊，形成庄严街景 |
| 交叉口 | 与经二路交汇处为商埠区最繁华地段，四角各设大型洋行/银行建筑 |
| 绿化 | 行道树以法桐、国槐为主，部分路段有修剪整齐的绿篱，【存疑】具体配置 |

### 2.2 典型洋行建筑形制（取 1920 年代盛期）

| 建筑类型 | 形制要点 |
|---|---|
| 德式新古典主义银行 | 2—3 层，石材或清水砖立面，对称构图，中央主入口设柱廊（多立克/爱奥尼克柱式），上方三角山花或弧形拱券；坡屋顶或穹顶；立面有线脚、浮雕、徽章装饰 |
| 英式古典主义洋行 | 2—3 层，红砖墙面，石材窗框与门套，坡屋顶，老虎窗，烟囱突出；风格较德式更沉稳内敛 |
| 中西合璧银行 | 西式立面（柱廊、拱窗）+ 中式坡屋顶与匾额；或西式主体 + 中式门楼 |
| 门廊与台阶 | 银行建筑主入口常设宽大石台阶 + 多柱门廊，彰显威严与可进入性 |
| 铁门与围栏 | 重要银行门前设铸铁大门与围栏，装饰性花纹，部分保留至今 |

### 2.3 招牌与标识

- 外资银行招牌中英文并列，德文/英文在上、中文在下，字体为老式衬线体
- 华资银行招牌以中文竖排繁体为主，木质匾额，鎏金或黑底金字
- 常见字号："德华银行""交通银行""山东民生银行"及各类票号钱庄名称
