## 一、史实概要（写作与画面叙事依据）

- **人物**：李清照（1084—约1155），号易安居士，济南章丘人，宋代最杰出的女词人，婉约词派代表，有"千古第一才女"之称。
- **与趵突泉关系**：李清照少年时期居济南，其故居据称在趵突泉附近。趵突泉公园内现存李清照纪念堂，但纪念堂建于**1959 年**，属现代建筑，不可直接作为宋代复原依据。
- **纪念堂现状**：位于趵突泉公园漱玉泉北侧，占地约 3000㎡，四合院布局，正厅坐北朝南，内有李清照塑像、生平展与手迹碑刻。院内有"漱玉堂""燕寝凝香"等匾额，郭沫若题联："大明湖畔趵突泉边故居在垂杨深处，漱玉集中金石录里文采有后主遗风"。
- **复原核心**：不应复原"纪念堂"本身（1959 年现代建筑），而应复原李清照**少年时代生活的宋代庭院与趵突泉周边风貌**，即以人物生活史为核心的历史场景。
- **少年李清照时间窗口**：约 1090—1100 年（6—16 岁），北宋哲宗至徽宗初年，济南属京东路齐州。

## 二、北宋济南与趵突泉环境（画面复原核心依据）

### 地理与泉脉
- 趵突泉为古泺水之源，北魏郦道元《水经注》已载"泺水出历城县故城西南，泉源上奋，水涌若轮"。宋代时趵突泉已是名胜。
- 泉池周边多垂杨、修竹、怪石，泉水清澈见底，三窟并发，声如隐雷。
- 宋代济南城垣位于今济南老城区一带，趵突泉在城西门外，属城郊园林地带，非严格"城中"。

### 宋代民居与庭院形制（画面核心依据）

| 部位 | 形制要点 |
|---|---|
| 院落格局 | 典型的北方**四合院**或**两进小院**，中轴对称，坐北朝南；围墙不高，常以夯土或青砖砌成 |
| 正厅/堂屋 | 三开间，**悬山顶或歇山顶**，青瓦屋面；出檐深远，檐下斗栱简洁；木构梁柱，朱漆门窗格扇 |
| 门窗 | **格子门**（槅扇），直棂窗或方格窗，木质，不上玻璃，糊纸或敞开；门框有简单木雕 |
| 墙面 | 外墙面**白灰抹面**或**青砖露明**；基座以青石或夯土包砖；无华丽彩绘，士大夫家可能有墨画或素彩 |
| 庭院 | 中庭铺砖或碎石，植**垂柳、修竹、芭蕉、海棠**；设石桌石凳；可能有小池引流泉水 |
| 室内陈设 | 书案（凭几、书几）、笔墨纸砚、琴、书卷轴；瓷枕、香炉；座椅为**玫瑰椅或灯挂椅**；地面铺方砖或木板 |
| 女子闺房 | 纱帐、锦被、妆奁、铜镜、针线笸箩；窗外可见花木 |

### 少女李清照形象依据
- 出身书香门第，父李格非为苏轼门生、官至礼部员外郎，母王氏亦善文。少女时代衣食无忧，受过良好教育。
- 史料中无直接外貌描述，但可从词作中推断气质：**聪慧、敏感、清秀脱俗**，不喜俗务，好读书、作词、赏玩金石。
- 服装应为**北宋士族女子日常装束**：窄袖褙子（或半臂）+ 长裙（襦裙），发式为双鬟或垂髻，面容淡妆，不戴繁复头面（少女时期）。色彩以淡雅为主——浅绿、淡粉、月白、藕荷色。
