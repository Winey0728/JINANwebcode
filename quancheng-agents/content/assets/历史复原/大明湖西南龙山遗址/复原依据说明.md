## 二、龙山文化聚落场景形制（画面复原核心依据）

### 2.1 聚落格局【存疑】——以城子崖等遗址考古报告为参照，具体细节需报告确认

| 部位 | 形制要点 |
|---|---|
| 聚落类型 | 环壕聚落或早期城址，外围有壕沟或土筑城墙；城内面积约数万平方米至数十万平方米不等 |
| 城墙/环壕 | 土筑城墙，底部宽约 10 米，高约 3—5 米，夯土筑成；或环壕宽 5—10 米，深 2—3 米 |
| 城门 | 城墙可能有简单的豁口或门道【存疑】——龙山文化城址的门道遗迹发现较少 |
| 内部布局 | 聚落内有成片房屋区、手工作坊区、墓葬区（可能分开）【存疑】——具体功能分区需考古报告确认 |

### 2.2 建筑形制【存疑】——以考古报告与同时期遗址复原为参照

| 部位 | 形制要点 |
|---|---|
| 房屋类型 | 半地穴式圆形/方形房屋或地面建筑；半地穴式为坑壁立木柱、顶部覆草顶；地面建筑为土坯墙或木骨泥墙 |
| 房屋尺寸 | 直径或边长约 3—6 米，面积约 10—30 平方米 |

| 墙体 | 半地穴式为坑壁立柱、编笆抹泥；地面式为土坯砌墙或木骨泥墙，墙厚约 30—50 厘米 |
| 地面 | 夯土地面，部分房屋地面经火烧硬化；半地穴式屋内地面低于室外约 0.5—1 米 |
| 门道 | 斜坡门道或台阶，设于房屋一侧 |
| 灶坑 | 屋内中央或近门处有圆形灶坑，用于取暖与炊煮 |

### 2.3 器物与生产活动

| 类别 | 形制要点 |
|---|---|
| 陶器 | **蛋壳黑陶**——龙山文化标志性器物，薄壁（最薄处 0.3—0.5 毫米）、乌黑发亮、表面磨光；器型有杯、豆、鼎、鬶、罐等；黑陶杯高柄、喇叭口，为典型礼器 |
| 石器 | 磨制石斧、石铲、石刀、石镞；石铲用于农业生产 |
| 玉器 | 玉钺、玉璋、玉璧等，为礼器或权杖，表明社会分化【存疑】——济南地区龙山遗址出土玉器情况需报告确认 |
| 农业 | 种植粟（小米）、黍；使用石铲、石锄耕作；聚落周边有农田 |
| 畜牧 | 饲养猪、狗、牛、羊等；猪为重要家畜，可能与祭祀相关 |
| 制陶 | 聚落内有制陶作坊，可见陶窑（横穴式或竖穴式）【存疑】——陶窑形制以考古报告为准 |

### 2.4 环境与景观

- **地形**：济南地处泰山北麓、黄河下游，地形以平原与低山丘陵为主；遗址位于大明湖附近，地势平坦，水源丰富。
- **植被**：距今 4000 年前后，济南地区为暖温带落叶阔叶林与草原交错带；聚落周边有栎树、榆树、杨树等阔叶林，以及芦苇、荻等湿地植物【存疑】——古植被重建需花粉分析报告确认。
- **水系**：大明湖为天然湖泊，周边泉水众多；聚落临水而建，壕沟可能与天然水系相连。
- **天气与光线**：夏末秋初，天气晴朗；光线明亮，以自然光为主；画面色调偏暖黄与土褐，体现远古质朴感。
