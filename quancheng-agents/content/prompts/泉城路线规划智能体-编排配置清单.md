# 编排配置清单（对照平台编排页逐项设置）

> 平台：HiAgent（agentlab.sdu.edu.cn）· 工作空间「汇水成脉智能体协作空间」
> 智能体：泉城路线规划智能体（对话型，待创建）
> 前置依赖：请先让刘子玥把 `路线规划数据底稿.md` 上传为第四个知识库（见第 0 步）

## 0. 前置：创建「路线规划资料库」知识库

1. 左侧菜单「知识库」→「创建知识库」，类型选**知识库**（标准型）
2. 名称：`路线规划资料库`；描述建议：济南景点路线规划数据卡（地理簇/停留时长/体力/交通/开放时间）
3. 上传文件：`quancheng-agents\prompts\路线规划数据底稿-v1.md`（版本化命名；团队修正后产出 v2 时，禁用/删除旧文件再导入新版，避免新旧混检）
4. 等文件列表显示"解析成功"后再进下一步

## 1. 创建智能体

- 应用 → Agent →「创建智能体」→ 类型选**对话型**
- 名称：`泉城路线规划智能体`
- 描述建议：济南泉城片区个性化游览路线规划师：按游览时间、兴趣偏好、体力状况、交通方式量身定制路线，时间轴分点输出，景点附画册跳转链接。

## 2. 模式

- 单 Agent 模式 ✅（默认）

## 3. 提示词

- 模式：Normal
- 内容：见 `泉城路线规划智能体-系统提示词.md`，全文粘贴
- ⚠️ ①踩过的坑：提示词编辑器是 contenteditable，直接粘贴大段文本偶尔失效；粘贴后务必目视检查全文完整，并确认页面顶部出现"草稿最后保存于 HH:MM:SS"

## 4. 模型选择（调试与预览右上角切换）

| 优先级 | 模型 | 理由 |
|---|---|---|
| 首选 | Doubao-Seed-1_6-thinking | 平台最新（2025-09），推理能力强，适合多参数路线编排 |
| 备选 | DeepSeek-V3_1 | 2025-09 发布，通用能力强（①现用模型，保持团队一致也可直接选它） |
| 保底 | SDU-AI/DeepSeek-V4-Flash | 本地部署（2026-04），速度快，但需实测效果 |

- 不建议：Doubao-1-5-pro-32k（默认，2025-05 老版本）、deepseekr1（延迟高）、本地 QwQ-32B（性能弱）

## 5. 记忆

| 配置项 | 建议值 |
|---|---|
| 长期记忆 | 开（记录用户偏好，如回头客的兴趣标签与体力状况） |

## 6. 技能

| 配置项 | 建议值 | 说明 |
|---|---|---|
| 插件 | **BingSearch（免费，加挂）** | 核对时效信息：今日亮灯时间、临时闭园、活动公告、"暂未收录"字段的补充查询。插件中心搜索"BingSearch"添加即可，无需付费配置 |
| 插件（可选进阶） | 高德地图 MCP（付费，暂不加） | 实时步行/公交路径规划+距离测量，需申请高德 API key 并配置；预算允许时再加，加了之后路线时间将从估值变为实时计算 |
| Skills / 工作流 / 智能体 / 触发器 | 不添加 | 本智能体不需要 |

## 7. 知识

| 配置项 | 值 |
|---|---|
| 知识库 | 挂载 4 个：「泉水文化知识库」「古城墙知识库」「泉水周边考古遗址」「路线规划资料库」 |
| 检索模式 | 默认（语义检索）；强制模式保持关闭 |
| 问答库 / 术语库 / 数据库 | 不添加 |

- ⚠️ 挂载方法（①踩过的坑）：知识库卡片上没有文字按钮，点卡片标题栏的**加号图标**（blow-up 图标），在弹出的「添加知识库」对话框中逐个勾选添加，页面显示"添加成功"即完成
- ⚠️ 若弹出「引用了未定义的变量」对话框，点「取消」关闭即可，不影响配置

## 8. 对话

- 见 `泉城路线规划智能体-对话配置.md`（开场白 + 3 条引导问题 + 开关值）

## 9. 系统

| 配置项 | 值 |
|---|---|
| 思考语言 | 简体中文 |

## 10. 发布前检查

1. 跑一遍 `泉城路线规划智能体-测试用例集.md`，达到验收标准
2. 点右上角【渠道发布】，可见范围与标签同①（私有配置 + "教学"标签）
3. 等待管理员审批（参考①的审批流程）
4. 审批通过后从「发布 → 已发布渠道」复制 Web 链接，交 Flipbook 组嵌入悬浮按钮
5. **链接回填（画册组交付链接清单后）**：拿到画册各景点页面 URL 清单后，把清单追加到「路线规划资料库」（或改提示词），将智能体输出中的 `[景点名](链接待补)` 占位符替换为真实链接——届时叫我，我来改文件
