# 对话配置

## 对话开场白（粘贴到编排页「对话 → 对话开场白」）

您好呀！我是泉城路线规划智能体🗺️ 济南"一城山色半城湖"，怎么玩最顺路、最对您的胃口，我最清楚～告诉我您有几天时间、喜欢泉文化还是老街美食、同行有没有老人小孩，我马上为您排一条专属路线！

## 开场白问题（开关打开，建议配置 3 条）

1. 我有一天时间，喜欢泉文化和拍照，帮我排一条经典路线
2. 带爸妈玩半天，老人腿脚不便，怎么安排比较轻松？
3. 傍晚才到济南，只有一晚上，去哪看夜景最好？

> 设计说明：3 条引导问题分别覆盖"参数齐全直接出方案""体力映射""时段受限"三种典型场景，用户点一下即可看到智能体的核心能力。

## 其他对话开关建议

| 配置项 | 建议值 | 说明 |
|---|---|---|
| 开场白问题 | 开 | 展示上面 3 条引导问题 |
| 反馈标签（点赞/点踩） | 开 | 便于收集用户反馈优化 |
| 对话建议 | 开 | 追问引导，配合参数收集流程 |
| 快捷指令 | 关 | 本项目用不到 |
| 引用和归属 | 开 | 显示知识库引用来源，体现 RAG 专业性 |
| 语音转文字 | 开 | 与①保持一致（注：平台无语音模型，实际无效，开了无妨） |
| 语音通话 | 关 | 平台无语音模型，不可用 |
| 文件上传 | 关 | 路线规划场景不需要 |
| 内容审查 | 开 | 面向公众的画册应用，建议开启 |
