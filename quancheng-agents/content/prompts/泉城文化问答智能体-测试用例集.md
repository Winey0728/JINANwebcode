# 测试用例集（发布前逐项验证）

## A. 知识库命中类（验证 RAG 准确性）

| # | 测试问题 | 期望要点 |
|---|---|---|
| A1 | 趵突泉为什么被称为"天下第一泉"？ | 引用泉水文化知识库：乾隆御封/三股水/泺水之源等史实 |
| A2 | 黑虎泉的泉水是从哪里冒出来的？ | 石雕虎头喷涌、护城河沿岸位置、市民打水习俗 |
| A3 | 济南"七十二名泉"都有哪些？ | 列举主要名泉，说明"七十二"为约数/历代名录变迁 |
| A4 | 大明湖和泉水有什么关系？ | 众泉汇流成湖、"恒雨不涨、久旱不涸"等特点 |
| A5 | 济南古城墙现在还剩下哪些遗迹？ | 引用古城墙知识库内容作答 |

## B. 游览建议类（验证实用信息能力）

| # | 测试问题 | 期望要点 |
|---|---|---|
| B1 | 帮我规划一条护城河沿岸的半日游路线 | 分点列出路线（如黑虎泉→解放阁→泉城广场→趵突泉），含时间建议 |
| B2 | 趵突泉附近有什么好吃的？ | 周边美食推荐；如知识库无数据需说明"一般性介绍" |
| B3 | 什么季节看泉水最好？ | 雨季/丰水期建议，结合泉水水位特点 |

## C. 多轮对话类（验证上下文理解）

| # | 对话序列 | 期望要点 |
|---|---|---|
| C1 | ①"趵突泉有什么传说？" ②"那它一年到头都不停喷吗？" | ②中"它"正确指代趵突泉，回答喷涌历史与停喷记录 |
| C2 | ①"讲讲大明湖" ②"还有呢？" | ②承接上文继续补充大明湖内容，不重复不跑偏 |

## D. 越界婉拒类（验证领域限制）

| # | 测试问题 | 期望要点 |
|---|---|---|
| D1 | 帮我写一段 Python 代码 | 礼貌婉拒 + 引导回泉城文化话题 |
| D2 | 青岛的栈桥好玩吗？ | 婉拒（非济南水系文化）+ 可顺势介绍济南类似景观 |
| D3 | 今天股市怎么样？ | 礼貌婉拒 + 引导回主题 |

## E. 事实底线类（验证不编造）

| # | 测试问题 | 期望要点 |
|---|---|---|
| E1 | 趵突泉现在的门票多少钱？ | 联网核对后回答，带"以官方公告为准"提示；不得无来源报数字 |
| E2 | 介绍一下济南的"百泉之城"称号由来 | 依据知识库/公认常识，不虚构文献出处 |

## 验收标准

- A 类：回答内容与知识库一致，无虚构史实；表达生动，非照搬原文
- D 类：100% 婉拒，且话术自然不生硬，符合"小泉"人设语气
- E 类：无无来源说明的具体数据（票价/开放时间）
- 整体：文化/攻略类回答充分展开（上限约 600 字），简单问题简明；语气亲切有讲解感
