## 一、地理簇总览

济南核心游览资源高度集中在**老城泉群核心簇**——这是排路线时最关键的一个事实：**老城核心簇各点基本步行可达**，一条顺向动线即可串起绝大多数景点，不需要中途打车。经典一日步行环线（与网络公开 Citywalk 路线一致）为：

> 趵突泉 → 五龙潭 → 泉城广场 → 黑虎泉 → 解放阁 → 宽厚里 → 芙蓉街 → 曲水亭街 → 百花洲 → 大明湖 → 超然楼（夜）

| 起点 → 终点 | 步行约 | 说明 |
|---|---|---|

## 五、餐饮衔接建议（街区级，不推荐具体店铺）

- **芙蓉街**：老城小吃最密集街区，适合安排午餐或晚餐时段顺路解决；节假日拥挤，带老人小孩可错峰或改道宽厚里。
- **宽厚里**：小吃与餐饮聚集，夜间氛围好，适合黑虎泉/解放阁游览后的晚餐衔接。
- **曲水亭街**：沿河茶馆集中，适合午后安排 30–60 分钟临水喝茶歇脚，兼作低体力游客的休息点。
- **泉城路商圈**：连锁餐饮与商场餐饮齐全，可作为雨天/高温天的正餐备选。

### 5.2 季节与天气提示（经验性建议）

- **春季（3–5 月）**：趵突泉玉兰、五龙潭樱花季，适合摄影主题路线；千佛山三月三庙会。
- **夏季（6–8 月）**：大明湖荷花季（7–8 月最佳）；正午炎热，按第六节避暑规则排室内节点；泉水受汛期补给通常更旺。
- **秋季（9–11 月）**：趵突泉水位通常一年最高，喷涌最壮观；灵岩寺千年银杏 11 月金黄，为摄影黄金期。
- **冬季（12–2 月）**：老舍笔下"济南的冬天"，雪中泉景别有韵味；护城河游船与亮灯时间可能因天气调整，以公告为准。
- **雨天备案**：山东手造展示体验中心、泉城路商圈室内节点替换户外泉边步行。

## 六、体力映射建议（老人/小孩/低体力游客通用调整规则）

1. **砍爬坡**：剔除千佛山登顶（或改索道上下）、灵岩寺上山步道、解放阁/超然楼登楼，只保留平地观景点。
2. **游船替代步行**：黑虎泉—趵突泉—大明湖之间优先用护城河游船分段代步；大明湖内用环湖观光车/游船代步。
3. **加休息点**：每 1.5–2 小时安排一次休息——曲水亭街茶馆、大明湖沿湖座椅、泉城广场树荫均可。
4. **控密度**：半天不超过 2–3 个景点；老城簇内优先选"趵突泉 + 黑虎泉 + 大明湖南岸"这类平坦精华组合。
5. **避暑避峰**：夏季正午安排室内节点（山东手造展示体验中心、商场），清晨与傍晚走户外泉边。
6. **远郊分级**：灵岩寺、明水古城对低体力游客按"独立一日游"安排，不与老城簇同日叠加。

## 七、路线规划速查提示（供智能体引用）

- 经典一日步行线：趵突泉 → 五龙潭 → 泉城广场 → 黑虎泉 → 解放阁 → 宽厚里（餐）→ 芙蓉街 → 曲水亭街 → 百花洲 → 大明湖 → 超然楼（亮灯收尾）。
- 老城簇全日步数约 1.5–2 万步，低体力用户按第六节规则拆分至一天半或用游船/观光车压缩。
- 千佛山适合单独半天（上午登山 + 下午接老城线）。
- 灵岩寺、明水古城各占一个一日游；两者不建议同日（方向相反）。
- 夜游组合：黑虎泉夜航游船 / 超然楼亮灯 / 宽厚里或芙蓉街夜市。
