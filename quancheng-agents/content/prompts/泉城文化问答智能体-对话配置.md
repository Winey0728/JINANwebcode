# 对话配置

## 对话开场白（粘贴到编排页「对话 → 对话开场白」）

您好呀！我是小泉🏞️ 在护城河边长大的泉城讲解员～济南"家家泉水，户户垂杨"，每一眼泉、每一段城墙都有讲不完的故事。您想听趵突泉的传说、大明湖的趣闻，还是让我推荐一条逛泉路线？尽管开口！

## 开场白问题（开关打开，建议配置 3 条）

1. 趵突泉为什么被称为"天下第一泉"？
2. 帮我规划一条护城河沿岸的半日游路线
3. 大明湖"蛇不见、蛙不鸣"是真的吗？

## 其他对话开关建议

| 配置项 | 建议值 | 说明 |
|---|---|---|
| 开场白问题 | 开 | 展示上面 3 条引导问题 |
| 反馈标签（点赞/点踩） | 开 | 便于收集用户反馈优化 |
| 对话建议 | 开 | 追问引导，提升多轮对话 |
| 快捷指令 | 关 | 本项目用不到 |
| 引用和归属 | 开 | 显示知识库引用来源，体现 RAG 专业性 |
| 语音转文字 | 开 | 项目要求支持语音输入问题 |
| 语音通话 | 关 | 非必需，且消耗资源 |
| 文件上传 | 关 | 问答场景不需要 |
| 内容审查 | 开 | 面向公众的画册应用，建议开启 |
