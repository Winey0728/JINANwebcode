- **文件**：`quancheng-agents/flipbook/index.html`
- **内容**：封面 → 目录（自动分组）→ 25 点位页（同构模板）→ 封底
- **功能**：左右翻页 / 键盘导航 / 触摸滑动 / 目录跳转 / 悬浮按钮（语音/复原/对话）/ 弹层系统
