- 套餐内可用模型（`/models` 实测）：`step-3.7-flash`、`step-3.5-flash`、`stepaudio-2.5-tts`、`stepaudio-2.5-asr`、`step-image-edit-2` 等。
- 实测结论：
  - 图像编辑 i2i `/images/edits`（multipart）：✅ 约 8s/张，0.02 元/张，构图继承好。
  - 文生图 `/images/generations`：✅ 约 4s/张；**size 仅支持 1360x768/1184x896/1024x1024/768x1360/896x1184**，横竖画幅可能被模型自选忽略。
  - TTS `/audio/speech`：**`step-tts-mini` 套餐内不可用（404 model_invalid），必须用 `stepaudio-2.5-tts`**；input 上限约 1000 字符，超限按句界切分段合成再拼接。默认语速偏快（中文 8-11 字/s，英文约 5 词/s）。
  - 对话 `/chat/completions`：`step-3.7-flash` 为思考型模型（有长 reasoning，**勿限 max_tokens**），翻译质量好；**套餐无 web_search 联网能力**；模型史实知识不可靠（实测答错黑虎泉虎头数），内容任务必须喂史料原文。

### 4.4 Prompt 方法论（血泪经验）

1. 短 prompt（≤512 字符）分层递减：首句定风格时代，次句定构图约束，元素按优先级递减。
2. 否定项 ≤3 组放末尾（"no X"里的 X 同样有注意力权重）。
3. 生图放弃渲染可读汉字，题字后期 P。
4. 上色场景与生成场景 prompt 完全不同：上色强调"preserve/unchanged/only add color"；生成强调风格与元素优先级。
5. 史实硬约束：黑虎泉**清末单虎头、1931 年后三虎**（碑刻+老照片实证），涉及黑虎泉的图/文/prompt 均须遵守；《复原依据说明.md》的口径回改仍待办。
