## 五、素材生产管线（本次重大变更：Agnes → Step）

### 5.1 Agnes 结论（降级为纯文生图）
- 端点 `https://apihub.agnes-ai.cn/v1`，模型 `agnes-image-2.1-flash`，Key 存 `quancheng-agents/assets/.env`（**绝不写入 md/代码**）。
- **image 参数实测≈无效**：对照实验（同 prompt 带图 vs 不带图）输出构图几乎一样；参考图 URL 过期也静默返回 200。实质是"文生图 + 至多微弱风格参考"，无 strength/denoise 可控。
- 平台无更强图像模型（`agnes-image-2.0-flash` 质量无提升且 503 频发）。
- 其他坑：size 写像素格式 `2048x1152`（输出实约 1312×736）；不传 `response_format`（会 400）；Base64 data URI 必被 Cloudflare 403，image 需公网 URL（filebin.net 取 302 签名直链，900s 内调用）；返回 URL 约 24h 有效须即下即存；批量需 503 重试退避。
- **定位：Agnes 仅作纯文生图备用，i2i 需求全部转 Step。**

### 5.2 Step（阶跃星辰）——新主管线
- 用户已购 **Step Plan 99 元档（Flash Plus）**。Key 存 `quancheng-agents/assets/.env` 的 `STEP_API_KEY`（**绝不写入文档/代码**）。
- **`step-image-edit-2`**：
  - 文生图：`POST /v1/images/generations`；
  - **图像编辑 `POST /v1/images/edits`（真 i2i）**：multipart form 提交，prompt ≤512 字符，输出与输入同尺寸，**0.02 元/张**。
  - 实测：民国拱门老照片编辑成功，**构图完全继承底图**——这是 Agnes 做不到的。
- **TTS**：`step-tts-mini` / `stepaudio-2.5-tts`，OpenAI 兼容 `POST /v1/audio/speech`。⚠️ **待打通**：Step Plan 专用路径 `/step_plan/v1/audio/speech` 试调返回 404——需查文档确认 Step Plan 的正确 base URL，或确认音频是否在套餐内。
- 注意点：官方示例图片生成 size 格式为"高x宽"如 `1360x768`；`cfg_scale=1.0` 时 negative_prompt 不生效。

### 5.3 Prompt 方法论（v5/v6 经验，详细见黑虎泉目录两份 md）
1. **短 prompt（≤512 字符）分层递减**：首句定风格，次句"Keep the composition of the reference photo"把构图交还底图，元素按优先级递减排列。长 prompt 后半段 token 权重被丢弃且自相打架。
2. **虎头按高清参考图写"无纹素面霸下"**（plain blocky carving, wide squared open mouth, bulging eyes…），**勿写虎纹/石狮**（stripes 会引向雕花石狮）。
3. **否定项 ≤3 组放末尾**（扩散模型对 "no X" 中的 X 同样有注意力，否定越多越画出来）。
4. **汉字题字生图放弃，后期 P 上**（图像模型渲染可读汉字失败率极高）。
5. **每点位跑 3–4 张选优 + 穿帮点验收卡**（模板见 `i2i试点验收卡.md`）。

## 十、操作经验继承区（旧文档仍有效内容）

### 10.1 WebBridge 自动化操作平台的坑
- 会话用 `session: "sdu-agentlab-recon"`；Windows 下必须写 JSON 文件再 `curl.exe --data-binary "@file"`，防中文损坏。
- **提示词编辑器（contenteditable）用 `fill` 会"假成功"**——有效方案：evaluate 聚焦+全选编辑器，然后 `cdp Input.insertText` 注入全文。
- 开场白等普通 contenteditable 用 `fill` 正常。
- 快照 `@e` 引用每次 snapshot 后刷新，跨操作复用报 "unknown ref"，需重新 snapshot。
- 平台反复弹「引用了未定义的变量」对话框，用 JS 批量点可见的「取消」按钮清除。
- 知识库卡片加号在卡片 header 的 `.operation-icon`。
- 开关状态检测 a11y 树不含状态，需 JS 查 `button.arco-switch` 的 aria-checked（不可靠，最终靠截图目视确认）。

### 10.2 平台通用规则
- 草稿自动保存（页面顶部"草稿最后保存于 HH:MM:SS"可验证）。
- 渠道配置修改后必须点右上角【渠道发布】生效；发布需管理员审批。
- **发布前先看发布页「历史发布记录」有没有别人的审批中单**，避免撞车（409 ApprovalDuplicated）。
- 本平台无"导出"功能；「导入智能体」仅接受 zip ≤100MiB；编排页右上角未标注按钮是「导入新版本」。
- 模型首选 **Doubao-Seed-1_6-thinking** 或 **DeepSeek-V3_1**；平台无 TTS / 图像生成 / 视频生成能力。
- 插件中心 57 个，用前先添加到工作空间；BingSearch（MCP 免费）已验证可用；高德地图 MCP 付费为进阶可选。
